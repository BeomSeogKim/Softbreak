# Writing app

An experiment to define and build a focused writing app.

## Current phase

The project is in discovery. No target writer, core writing job, platform, or technical stack has been selected yet.

## Next decision

Choose the first user and the one writing moment the app should improve. The initial concept should state:

- who it serves;
- what they are trying to write;
- the obstacle the app removes;
- the smallest complete writing flow; and
- how we will tell whether it helped.
