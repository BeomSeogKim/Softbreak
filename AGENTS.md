# Project instructions

## Context

This is an early experiment for a writing app. The product concept and technical stack are deliberately undecided.

## Working rules

- Keep changes minimal and appropriate to the discovery phase.
- Do not scaffold an application, install dependencies, or choose a framework until the target writer and smallest complete writing flow are explicit.
- Record product questions, concepts, evidence, and decisions in `notes/IDEATION.md`.
- Write project documentation, code, configuration, and comments in English. Communicate with the owner in Korean unless asked otherwise.
- Manage future local secrets with sealbox using the project name `writing-app`; do not create a committed `.env` file.
- Preserve user changes and avoid unrelated cleanup.

## Current success criterion

Discovery is complete when one concept has an explicit target writer, writing moment, problem, smallest complete flow, and a way to validate whether it helps.
